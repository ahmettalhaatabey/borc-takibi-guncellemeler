# Borç Takibi

Borç, alacak, gelir ve gider takibi için Windows uygulaması. Veriler yalnızca sizin bilgisayarınızda durur.

## Kurulum

1. **[Son sürümü indirin](https://github.com/ahmettalhaatabey/borc-takibi-guncellemeler/releases/latest)**: "Assets"
   altındaki `Borc-Takibi-Kurulum-….exe` dosyası.
2. Dosyayı açın. Windows "Bilgisayarınız korundu" derse **Ek bilgi → Yine de çalıştır**'a basın
   (uygulama imzasız olduğu için çıkan bir uyarıdır).
3. Kurulacak klasörü seçin (ör. `D:\Programlar\BorcTakibi`). Verileriniz bu klasörün içindeki `Veriler`
   klasöründe tutulur.

## Güncellemeler

Kurduktan sonra bir şey indirmeniz gerekmez. Uygulama yeni sürümleri kendisi bulup arka planda indirir;
"Yeni sürüm hazır" yazısına basınca ya da uygulamayı kapatınca kurulur. Verileriniz korunur.

> Bu depo yalnızca kurulum dosyalarını içerir.
